# 3.5頭身キャラクター組み立て

Court Legacy の選手キャラクターは外部画像を使わず、`appearanceSeed` と選手状態から軽量なSVGを組み立てます。同じセーブデータの同じ選手は、再読込後も同じ顔・髪型・体格・装飾になります。

## 固定される外見

- 身長帯: 小柄、標準、高身長、超高身長
- 体格: 細身、標準、筋肉質、大柄
- 顔型、目、眉、口
- 髪型、髪色、肌色
- ヘッドバンド、スポーツ眼鏡、テーピング、リストバンド
- ユニフォーム模様とポーズ

外見の組み合わせは `appearanceSeed` から個別のsaltで算出します。初期チームでは、外見シグネチャがほぼ重複しないことを単体テストで確認します。

## 状態で変化する表情

顔や髪型などの本人らしさは維持し、試合や練習で変わる状態は表情だけへ反映します。

1. 怪我中: 苦痛
2. 疲労85以上: 消耗
3. コンディション40以下: 不安
4. 士気78以上: 自信
5. 疲労60以上: 疲れ
6. その他: 集中または通常

## 描画

`PlayerCharacter` は `viewBox="0 0 80 112"` の3.5頭身SVGです。学校のユニフォーム3色を受け取り、選手カード、コート編成、練習選択で共通利用します。SVGは装飾扱いとし、選手名・学年・ポジション・状態は既存のテキストで読み上げ可能な状態を保ちます。

## 検証

- 同じseedで同じ外見になること
- 状態変化で外見本体が変わらず表情だけ変わること
- 身長帯と体格が反映されること
- 同一チームで近似キャラクターが過度に発生しないこと
- 学校ユニフォーム色がSVGへ反映されること
- スマホ幅で横スクロールが発生しないこと
