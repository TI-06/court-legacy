# 選手特殊能力 初期100種案

更新日: 2026-09-24

## 方針

- パワプロ系の「数値だけでは表せない個性」を高校バレー向けに置き換える。
- 保存データには能力IDだけを保持し、名称・説明・効果量は静的カタログ側に置く。
- 青特55 / 赤特20 / 上位特能15 / 金特10、合計100。
- 青特と赤特の対になる能力は同時所持不可。獲得時は相反能力を置換する。
- 上位特能は対応する青特を複数所持またはコツ蓄積で昇格可能。
- 金特は「通常条件 + 試合実績 + レアイベント/合宿成功」を基本条件とする。
- 強化合宿は能力値上昇だけでなく、特殊能力のコツ・習得・赤特除去・低確率で赤特付与の主要ルートにする。

## 獲得ルート案

- 通常練習: 関連能力の「コツ」を低確率で獲得。
- 個人練習: 指定分野の青特コツ確率を高める。
- 練習試合: 特定プレー成功回数で青特コツ・赤特改善判定。
- 公式戦: 接戦・格上戦・大会終盤でメンタル系を抽選。
- ランダムイベント: 青特/赤特の両方を対象にする。
- 選手関係イベント: 連携・キャプテン・セット系を中心にする。
- 強化合宿: 重点テーマに応じて青特コツ、赤特除去、上位特能昇格判定。高負荷時は赤特や怪我もあり得る。
- 金特: 対応する上位特能 + 実績 + レアイベント成功を基本条件にする。

## 実装時の保存方針

```ts
interface Player {
  specialAbilityIds: string[];
  specialAbilityTipLevels?: Record<string, 0 | 1 | 2 | 3>;
}
```

名称、説明、効果量、競合関係、昇格先は静的カタログに置き、セーブ側にはIDと必要最小限のコツLvだけを保存する。
