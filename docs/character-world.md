# キャラクター世界観

Court Legacy の新規ゲームでは、学校テーマと看板選手を使ったオリジナルの高校バレー世界が生成されます。

## 表示方式

- 看板選手は、氏名と所属校から専用の髪色、差し色、瞳色、役割名、背番号を解決します。
- 一般選手は `appearanceSeed` から決定論的に外見と背番号を生成します。
- 学校の配色とエンブレムは、選手タイル、ホームのチームフェイス、育成、編成、イベントへ共通で反映されます。
- キャラクターは外部画像を読み込まず、軽量なSVGレイヤーで描画します。
- 既存セーブの永続化スキーマは変更していません。看板選手が存在しない過去データでは、一般選手用の表示へ自動的にフォールバックします。

## 対応画面

- ホーム
- チーム編成
- 週間練習
- イベント

## レビュー項目

- ユニフォーム内の学校エンブレムは、選手カード用エンブレムと独立した寸法で表示します。
- チームフェイスは320px幅でも立ち絵と能力欄が重ならない構成にします。
- ライバル選手のイベントでは、自校色ではなく当事者の所属校テーマを使用します。

## 今後の拡張

同じ学校テーマと描画基盤を使い、試合中の立ち絵、表情差分、ライバル校の追加、特別世代選手の演出へ拡張できます。
