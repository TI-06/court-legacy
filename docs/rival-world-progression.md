# Rival World Progression

Court Legacy のライバル校は、年度更新ごとに監督能力、学校アーキタイプ、設備の影響を受けて成長します。ユーザー校の選手はこの自動成長処理の対象外です。

## 年度進行

- アーキタイプの重点能力を優先して選手能力を成長させる
- 評判、監督のスカウト力、スカウト網に応じて新入生が有望株へ昇格する
- 上位8人の戦力、監督能力、設備から年度評価を算出する
- 直近3年の年度評価から評判、資金、設備を成長または衰退させる
- 評判は0〜1000、設備は0〜5の範囲に収める

## 因縁と宿命校

試合ごとに次の条件を因縁度へ加算します。

- 対戦したこと自体
- フルセットなどの接戦
- 格上を倒す番狂わせ
- 同じ学校との再戦
- 大会での対戦
- 決勝での対戦

因縁度が60以上になった相手のうち最高値の学校を宿命校として記録します。公式戦の勝敗数は大会IDを持つ試合だけ更新し、練習試合は因縁度と試合履歴だけへ反映します。

## 長期保存上限

- 試合履歴: 500件
- 卒業生サマリー: 640件
- 各校の保持OB: 40人
- 保持する世代級選手ID: 64件

30年の決定論テストと100年の境界テストにより、同じシードで同じ世界が生成されること、選手・履歴・OBが無制限に増えないことを検証します。
