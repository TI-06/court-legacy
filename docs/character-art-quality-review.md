# キャラクターアート品質レビュー

## 結論

主要4選手は専用WebPを継続利用する。一般選手は、全身画像を68px前後まで縮小する方式では顔・表情・髪型が判別できなかったため、顔と上半身を優先した高品質ポートレートアトラスへ変更する。

この変更は Issue #29 の第1段階であり、既存の高品質原画を使ってゲーム画面上の見た目を先に改善する。顔・目・眉・口を完全に独立したパーツとして増やす作業は、Issue #29の後続タスクとして継続する。

## 今回の改善対象

- `src/assets/player-parts/v1/all-parts-atlas.webp`
- `scripts/generate_general_player_headshot_atlas.py`
- `src/ui/player-art/generatedArtManifest.ts`
- `src/ui/player-art/player-art.css`
- 一般選手のカード、編成、選手詳細表示

## 実装内容

- 既存の透過済み高品質原画4名から顔・上半身領域を抽出する。
- 左右反転を含む8種類の頭部・髪シルエットを用意する。
- 4種類の体格補正と組み合わせ、32種類の基本ポートレートを生成する。
- 髪型だけでなく、顔型、目、眉、口、身長帯、体格、ポーズ、ユニフォーム柄をポートレート選択へ反映する。
- 髪色、ユニフォーム主色、アクセント色を選手・学校データから適用する。
- 小さい編成枠では親要素に合わせて縮小し、選手一覧では最大68pxまで表示する。

## 継続する仕様

- `appearanceSeed` から同じ選手の外見を再現する。
- 固定4名は専用WebPを優先する。
- 選手キャラクターSVGへフォールバックしない。
- 必須画像の読み込み失敗時は選手画像全体を非表示にする。
- 選手能力、試合、育成、年度更新、セーブ形式を変更しない。
